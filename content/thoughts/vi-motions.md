# Vi Motions

## Command line

- `:` — enter command-line mode (`:help :` for the full list)

## Basic navigation

- `h` — left
- `j` — down
- `k` — up
- `l` — right
- `w` — next word start
- `b` — previous word start
- `B` — previous WORD start
- `e` — next word end
